# TS-001 - უფასო კონსულტაციის მოთხოვნის ფორმის ფუნქციონალის შემოწმება

**მიზანი:** 
შემოწმდეს, შეუძლია თუ არა მომხმარებელს უფასო კონსულტაციის მოთხოვნის სწორად შევსება და გაგზავნა, ასევე სწორად მუშაობს თუ არა ფორმის ვალიდაცია ვალიდური და არავალიდური მონაცემების შეყვანისას.

# TS-002 - სოციალური ქსელების ბმულების ფუნქციონალის შემოწმება

**მიზანი:** 
შემოწმდეს, ვებგვერდზე განთავსებული სოციალური ქსელების აიქონებზე დაჭერით შეუძლია თუ არა მომხმარებელს გადავიდეს კომპანიის ოფიციალურ გვერდზე შესაბამის სოციალურ ქსელში. 

# TS-003 - ვებგვერდის Cross-browser თავსებადობის შემოწმება

**მიზანი:** 
შემოწმდეს ვებგვერდის ძირითადი ფუნქციონალის და ვიზუალური ელემენტების გამართულად მუშაობა სხვადასხვა ბრაუზერში.
