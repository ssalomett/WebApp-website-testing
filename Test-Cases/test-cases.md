- ტელეფონი: 555123123

## TC-10 - ველების ვალიდაციის Cross-browser შემოწმება

** Scenario ID:** TS - 003

**ტესტირების ტიპი:** Cross-browser Testing

**მიზანი:** 

შემოწმდეს, მუშაობს თუ არა ველების ვალიდაცია სხვადასხვა ბრაუზერში

**Predictions:**

მომხმარებელი იმყოფება WebApp-ის მთავარ გვერდზე ( https://www.webapp.ge/ ) და გახსნილი აქვს უფასო კონსულტაციის შესავსები ფორმა

**Test Data**

ყველა ველი ცარიელია

**ბრაუზერები:**
- Google Chrome
- Opera

**Steps:** 

1. გავხსნათ ვებაპის მთავარი გვერდი Google Chrome-ში
2. უფასო კონსულტაციის შესავსებ ფორმაში არ ვავსებთ არცერთ ველს
3. მოვნიშნოთ თანხმობა, რომ გავეცანით მომსახურების პირობებს და კონფიდენციალურობის პოლიტიკას
4. დავაჭიროთ განაცხადის გაგზავნის ღილაკს
5. დავაკვირდეთ ვალიდაციისთვის შეტყობინებებს
6. გავიმეოროთ იგივე ნაბიჯები Opera-ში
7. შევადაროთ validation ქცევა ორივე ბრაუზერში

**Expected Result:** 

არცერთ ბრაუზერში ფორმა არ უნდა გაიგზავნოს, ველებთან უნდა გამოჩნდეს შესაბამისი ვალიდაციის შეტყობინება, რომ შესავსებია ველი

**Actual Result:**
