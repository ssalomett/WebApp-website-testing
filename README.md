# WebApp-website-testing

ეს პროექტი შექმნილია WebApp-ის ვებგვერდის ფუნქციონალისა და მომხმარებლის გამოცდილების შესამოწმებლად.

## პროექტის ფარგლებში განხორციელდა:

- Test Scenarios შექმნა
- Test Cases შექმნა და შესრულება
- Functional Testing
- Input Validation Testing
- Boundary Value Testing
- Cross-browser Testing
- Bug Reports-ის შექმნა და დოკუმენტირება
- აღმოჩენილი პრობლემების დეტალური აღწერა და რეპროდუცირება

ტესტირების შედეგად გამოვლინდა რამდენიმე ფუნქციური და ვალიდაციის პრობლემა, რომლებიც დოკუმენტირებულია Bug Reports-ის განყოფილებაში.
