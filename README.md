# WebApp-website-testing

ეს პროექტი შექმნილია WebApp-ის ვებგვერდის ( https://webapp.ge/ ) ფუნქციონალისა და 
მომხმარებლის გამოცდილების მანუალური ტესტირებისთვის.

## შესრულებული სამუშაო
- Test Scenarios-ის შემუშავება (3 სცენარი)
- Test Cases-ის შექმნა და შესრულება (10 ტესტ-ქეისი)
- Functional, Input Validation, Boundary Value და Cross-browser Testing
- Bug Reports-ის დოკუმენტირება (3 ბაგი, სრული repro-ნაბიჯებით)

|---|---|---|
| Bug-001 | ტელეფონის ველი იღებს ქართულ ასოებს ციფრების ნაცვლად | High |
| Bug-002 | Email ვალიდაცია არ მუშაობს არასწორ ფორმატზე | High |

დეტალური აღწერა იხილეთ `Test Cases.md` და `Bug Reports.md` ფაილებში.

## შენიშვნა
ვინაიდან webapp.ge აქტიური, საწარმოო საიტია, ტესტირებისას გამოყენებული 
იყო ტესტური მონაცემები (fake email/სახელები), რათა თავიდან ავირიდო 
რეალურ სისტემაში (მეილი, CRM) არარელევანტური ჩანაწერების დაგროვება.
